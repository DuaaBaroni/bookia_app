# bookia_app
# 📚 Bookia
A comprehensive e-commerce mobile application for buying and reading books, built with Flutter.

#🎯 Overview
Bookia is a modern e-commerce mobile application designed for book lovers. The app provides a seamless shopping experience with features including browsing books, managing cart, placing orders, and tracking order history.

# Key Highlights
-  Platform: iOS & Android (Flutter)
- 🎨 Design: Clean, modern UI/UX
- 🔐 Authentication: Secure login/register with JWT
- 🛒 E-commerce: Full shopping cart and checkout
- 👤 Profile: Complete user profile management
- 📦 Orders: Order tracking and history
- 🌐 API Integration: RESTful API with Dio
- 🎭 State Management: BLoC/Cubit pattern
- 💾 Local Storage: SharedPreferences for token storage
- Localization: uses easy localization
